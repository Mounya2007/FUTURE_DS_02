# Customer Retention & Churn Analysis

## 📊 Overview
This project analyzes customer churn patterns to identify why customers leave and how to improve retention.

## 🛠 Tools Used
- Python
- Pandas
- Matplotlib
- Google Colab

## 📈 Analysis Done
- Churn distribution
- Churn by gender
- Churn by contract
- Tenure-based churn trends

## 🔍 Key Insights
- High churn in short-term customers
- Month-to-month contracts have higher churn
- Long-term customers are more stable

## 💡 Recommendations
- Encourage long-term subscriptions
- Improve onboarding process
- Identify at-risk customers early
